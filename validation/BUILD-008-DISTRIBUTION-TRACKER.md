## Response taxonomy

Do not collapse all replies into "positive" or "negative".

Use:
- INTERESTED — asks for demo/artifact/call
- FORWARDED — routed to another team/person
- QUESTION — asks a substantive workflow/product question
- NOT_NOW — relevant but timing/budget unavailable
- NOT_FIT — explicit workflow mismatch
- NO_REPLY — only after a defined follow-up window
- BOUNCED — delivery failure
- UNKNOWN — not yet classified

## Measurement rule

A sent email is distribution activity, not validation.

Validation begins when there is a real response, introduction, meeting, workflow confirmation, pilot request, or other attributable action.

`PUBLICATION → OUTREACH → RESPONSE → WORKFLOW VALIDATION → PILOT → PAYMENT`
